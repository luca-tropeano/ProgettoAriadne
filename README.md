# ARIADNE Data-driven Materials Recovery System
###  Futuredata Srl
#### Ariadne Data-driven Materials Recovery System is a software platform that helps recycling plant operators recover valuable materials from electronic waste (WEEE). It identifies devices via camera (OpenCV) or barcode, retrieves the Bill of Materials and material declarations from a structured SQL database, and guides operators through manual disassembly with color-coded sorting instructions. The database — implemented directly in SQL (not Excel) — tracks which materials are present, how many (mass), and where (which component) in each device, enabling targeted recovery of critical raw materials that conventional shredding would lose.
